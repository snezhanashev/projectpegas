# Проект «PEGAS»

## Описание проекта

Веб-приложение для организации конеперевозок по России. Платформа соединяет клиентов, нуждающихся в перевозке лошадей, с водителями-исполнителями.

## Технологический стек

- **Backend**: Node.js + Express
- **Frontend**: React.js
- **База данных**: PostgreSQL
- **Карта**: Яндекс.Карты
- **Оплата**: Яндекс.Касса

## Использование

Для клиентов:

- Создание заявок на перевозку
- Просмотр доступных рейсов
- Бронирование мест
- Оплата услуг

Для водителей:

- Создание рейсов
- Управление заявками
- Общение с клиентами
- Получение оплаты

## Результаты аудита

Выявлены основные узкие места в процессе поставки ПО:

- Тестирование интеграции с картами
- Обработка платежей
- Синхронизация данных между клиентом и водителем
